## 1. Objetivo

Definir cómo se modela y sincroniza la identidad global del usuario entre la infraestructura de autenticación de Supabase (`auth.users`) y el esquema público de la aplicación (`public.users`).

---

# 2. Mapeo de Identidad y Sincronización Automática

$$\mathbf{auth.users}\ (\text{Identidad T\text{é}cnica}) \xrightarrow{\text{Trigger PostgreSQL}} \mathbf{public.users}\ (\text{Perfil Operativo NEGOVA})$$

```sql
-- Trigger transaccional de alta fidelidad
CREATE TRIGGER trg_on_auth_user_created
AFTER INSERT ON auth.users
FOR EACH ROW EXECUTE FUNCTION public.handle_new_auth_user();
```

### Atributos en `public.users`:
- `id`: UUID idéntico a `auth.users.id` (Clave foránea `ON DELETE CASCADE`).
- `full_name`: Nombre completo del colaborador.
- `phone`: Número de contacto.
- `avatar_url`: Imagen de perfil.
- `status`: Estado de la cuenta global (`active`, `inactive`, `suspended`).
