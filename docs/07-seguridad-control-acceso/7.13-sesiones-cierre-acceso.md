## 1. Objetivo

Definir los mecanismos de revocación inmediata de acceso ante eventos de cierre de sesión, suspensión de cuenta, revocación de membresía o cambio de credenciales.

---

# 2. Causales de Revocación de Acceso

```text
┌─────────────────────────────────────────────────────────────┐
│ EVENTO DE SEGURIDAD       │ EFECTO INMEDIATO EN LA SESIÓN   │
├───────────────────────────┼─────────────────────────────────┤
│ Logout voluntario         │ Invalidación de token en Supabase│
│ Cambio de contraseña      │ Revocación de refresh tokens    │
│ Cuenta global suspendida  │ Bloqueo en login (public.users) │
│ Membresía suspendida      │ Acceso denegado a ese tenant    │
│ Negocio suspendido        │ Bloqueo operativo a todo el staff│
└─────────────────────────────────────────────────────────────┘
```
