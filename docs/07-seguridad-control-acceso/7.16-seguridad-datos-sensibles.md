# 2. Clasificación de Datos y Reglas de Custodia

```text
TIPO DE DATO                UBICACIÓN PERMITIDA         ESTRATEGIA DE PROTECCIÓN

Tarjetas de Crédito         Pasarela Externa (Wompi)    NEGOVA nunca almacena CVV ni números
```
