## 1. Objetivo

Asegurar la consistencia relacional multi-tenant en el motor de base de datos, impidiendo que entidades dependientes (como ítems de comanda, pagos o despachos) puedan asociarse a recursos pertenecientes a otro comercio.

---

# 2. El Principio de Integridad Compuesta

```text
┌─────────────────────────────────────────────────────────────┐
│ ❌ RELACIÓN INVÁLIDA (Violación Multi-Tenant):              │
│ Pedido del Negocio A ──► Producto del Negocio B             │
├─────────────────────────────────────────────────────────────┤
│ ✅ RELACIÓN VÁLIDA (Consistencia Garantizada):              │
│ Negocio A ──► Pedido A ──► Ítem de Pedido A ──► Producto A  │
└─────────────────────────────────────────────────────────────┘
```

### Implementación Física en SQL:
```sql
CONSTRAINT fk_order_items_product_business
FOREIGN KEY (product_id, business_id)
REFERENCES public.products(id, business_id)
```
