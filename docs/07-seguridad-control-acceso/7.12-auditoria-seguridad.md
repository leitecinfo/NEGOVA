## 1. Objetivo

Definir la arquitectura de trazabilidad y registro forense de seguridad en NEGOVA, asegurando que toda acción sensible quede registrada de forma indeleble.

---

# 2. Eventos Sujetos a Auditoría Obligatoria

```text
ACCIÓN AUDITADA         DESCRIPCIÓN
─────────────────────────────────────────────────────────────────────────────
LOGIN / LOGOUT          Registro de accesos y cierres de sesión con IP y agente.
CREATE                  Creación de pedidos, productos, clientes y usuarios.
UPDATE                  Modificación de precios, datos de clientes o perfil.
DELETE / ARCHIVE        Baja lógica de insumos, combos o categorías.
STATUS_CHANGE           Transiciones de estado de comanda (preparing -> ready).
PERMISSION_CHANGE       Alteración de permisos asignados a roles locales.
SUBSCRIPTION_CHANGE     Cambio de plan o facturación del comercio.
```

$$\mathbf{Registro} = \langle \text{Actor (user\_id)},\ \text{Acci\text{ó}n},\ \text{Entidad},\ \text{Negocio},\ \text{Fecha/Hora},\ \text{IP/Origen},\ \text{Diff} \rangle$$
