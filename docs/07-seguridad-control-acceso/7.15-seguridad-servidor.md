## 1. Objetivo

Establecer que la autoridad final de seguridad e integridad de datos reside de forma indelegable en el **Servidor (Server Actions)** y en el **Motor de Base de Datos (PostgreSQL RLS)**.

---

# 2. La Falacia de la Seguridad en la Interfaz

```text
┌─────────────────────────────────────────────────────────────┐
│ ❌ FALACIA: "El botón está oculto, por tanto es seguro"     │
│ (Un atacante puede invocar la API o Server Action por cURL) │
├─────────────────────────────────────────────────────────────┤
│ ✅ DEFECTO POR DISEÑO EN NEGOVA:                            │
│ Frontend (UX) ──► Server Action (Zod + RBAC) ──► Postgres RLS│
│ Si la petición no tiene permiso en servidor, es RECHAZADA.  │
└─────────────────────────────────────────────────────────────┘
```
