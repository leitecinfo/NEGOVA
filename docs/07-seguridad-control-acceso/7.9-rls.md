## 1. Objetivo

Definir el rol de **Row Level Security (RLS)** en PostgreSQL como la barrera de seguridad de última milla que garantiza el aislamiento a nivel de filas, independientemente de cualquier fallo o vulnerabilidad en el frontend o servidor.
