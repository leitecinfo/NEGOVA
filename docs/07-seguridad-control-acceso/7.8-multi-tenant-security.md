## 1. Objetivo

Establecer la regla inviolable de aislamiento de datos entre comercios (*Multi-Tenant Isolation*), garantizando la mitigación total contra vulnerabilidades de acceso directo a objetos (**IDOR - Insecure Direct Object References**).

---

# 2. La Regla Inviolable de Aislamiento

> 🛡️ **Principio de Aislamiento Absoluto:**  
> Un usuario perteneciente al **Negocio A** bajo ninguna circunstancia puede consultar, modificar, crear o eliminar datos pertenecientes al **Negocio B**, incluso si:
> - Conoce el UUID exacto del registro o del comercio.
> - Descubre o adivina el `order_number`, `customer_id` o `product_id`.
> - Modifica manualmente los parámetros en la URL o en el cuerpo de una petición HTTP/JSON.
> - Utiliza herramientas de intercepción de tráfico (Postman, Burp Suite, cURL).
