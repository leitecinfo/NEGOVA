## 1. Objetivo

Aplicar el **Principio de Mínimo Privilegio (Principle of Least Privilege - PoLP)** a nivel de toda la arquitectura de usuarios, roles, servicios y conexiones de base de datos en NEGOVA.

---

# 2. Aplicación Práctica del PoLP

```text
┌─────────────────────────────────────────────────────────────┐
│ ❌ ANTIPATRÓN:                                              │
│ Otorgar permisos globales o de administrador a todo el      │
│ personal de cocina para "facilitar el trabajo".             │
├─────────────────────────────────────────────────────────────┤
│ ✅ MODELO NEGOVA (Principio de Mínimo Privilegio):          │
│ • Personal de Cocina: Solo 'orders.view' y 'orders.manage'. │
│ • Repartidor: Solo 'deliveries.view' y 'deliveries.manage'. │
│ • Propietario: Acceso administrativo acotado a su tenant.   │
└─────────────────────────────────────────────────────────────┘
```

> **Beneficio:** Minimiza drásticamente la superficie de ataque y el impacto de cuentas comprometidas o errores operativos accidentales.
