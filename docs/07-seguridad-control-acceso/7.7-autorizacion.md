## 1. Objetivo

Definir el flujo secuencial de autorización que valida de forma autoritaria si un usuario tiene la facultad de ejecutar una acción específica sobre un recurso dentro del comercio activo.

---

# 2. Flujo de Decisión de Autorización

```mermaid
flowchart TD
    A([Solicitud de Operación]) --> B{¿Está Autenticado?}
    B -- No --> C[DENEGAR: 401 Unauthorized]
    
    B -- Sí --> D{¿Pertenece al Negocio con Membresía Activa?}
    D -- No --> E[DENEGAR: 403 Forbidden]
    
    D -- Sí --> F{¿Su Rol Posee el Permiso Requerido?}
    F -- No --> E
    
    F -- Sí --> G{¿La Operación Cumple las Reglas de Negocio?}
    G -- No --> H[DENEGAR: 422 Unprocessable Entity]
    
    G -- Sí --> I[Evaluar RLS en PostgreSQL]
    I --> J([EJECUTAR Y RETORNAR RESULTADO])
```
