## 1. Objetivo

Definir las directrices de seguridad para el rol `SUPER ADMIN`, asegurando que sus privilegios globales de plataforma operen bajo canales controlados y auditados sin vulnerar el aislamiento de los tenants en la operativa ordinaria.

---

# 2. Separación de Ámbitos

```text
                      PLATAFORMA NEGOVA
                              │
           ┌──────────────────┴──────────────────┐
           │                                     │
    ÁMBITO PLATAFORMA                     ÁMBITO TENANTS
           │                                     │
      SUPER ADMIN                           OWNER / STAFF
 ├── Rutas /platform/*                  ├── Rutas /[businessSlug]/*
 ├── Funciones SECURITY DEFINER         ├── Operaciones ordinarias
 └── Gestión de planes y features       └── RLS estricto por tenant
```

> 🔒 **Regla de Seguridad:** El Super Administrador no debe operar como un usuario ordinario con bypass indiscriminado en el frontend; toda acción de plataforma se ejecuta mediante funciones de servidor protegidas.
