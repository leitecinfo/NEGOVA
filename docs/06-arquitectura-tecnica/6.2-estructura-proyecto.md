## 1. Objetivo

Definir la estructura de directorios y organización del código fuente en Next.js (App Router), separando nítidamente las capas de presentación, lógica de dominio por características (*features*), esquemas de validación, servicios de integración y contratos de datos.

---

# 2. Árbol General de Directorios (`src/`)

```text
NEGOVA/
├── public/                       # Activos estáticos públicos (logos, favicon, manifest)
├── supabase/                     # Migraciones SQL locales y semillas de prueba
│   └── migrations/
├── src/
│   ├── app/                      # Rutas, layouts y páginas de Next.js (App Router)
│   ├── components/               # Componentes UI reutilizables y layout global
│   ├── features/                 # Módulos funcionales de dominio (Feature-Driven)
│   ├── lib/                      # Clientes de infraestructura (Supabase, Auth, Utils)
│   ├── services/                 # Adaptadores e integraciones con servicios externos
│   ├── hooks/                    # Custom React Hooks compartidos
│   ├── schemas/                  # Esquemas de validación Zod reutilizables
│   ├── types/                    # Definiciones TypeScript globales y base de datos
│   ├── config/                   # Constantes de configuración, site config y navegación
│   └── utils/                    # Funciones utilitarias puras (formato moneda, fechas)
├── .env.example                  # Variables de entorno documentadas
├── package.json                  # Dependencias y scripts de construcción
├── tailwind.config.ts            # Configuración de diseño Tailwind
└── tsconfig.json                 # Configuración de compilación TypeScript
```

# 3. Detalle y Responsabilidad de Carpetas Principales

### 3.1 `src/app/` — Enrutamiento y Páginas (App Router)
Organizado en Route Groups (`(auth)`, `(dashboard)`, `(public)`, `platform`):
```text
src/app/
├── (auth)/                       # Rutas de Autenticación
│   ├── login/page.tsx
│   ├── recover/page.tsx
│   └── layout.tsx
├── (dashboard)/[businessSlug]/   # Panel Administrativo del Negocio
│   ├── dashboard/page.tsx        # Resumen de turnos y KPIs
│   ├── orders/page.tsx           # Cola de cocina y comandas
│   ├── menu/page.tsx             # Catálogo y modificadores
│   ├── customers/page.tsx        # Directorio de clientes
│   ├── finances/page.tsx         # Ventas, pagos y caja
│   ├── expenses/page.tsx         # Registro de egresos
│   ├── deliveries/page.tsx       # Módulo opcional de entregas
│   ├── settings/page.tsx         # Configuración del comercio
│   └── layout.tsx                # Sidebar, Tenant Switcher y Contexto
├── (public)/m/[businessSlug]/    # Menú Digital Público (Sin Login)
│   ├── page.tsx                  # Catálogo de platos y categorías
│   ├── checkout/page.tsx         # Carrito y confirmación
│   ├── order/[orderId]/page.tsx  # Seguimiento de estado en vivo
│   └── layout.tsx
├── platform/                     # Panel Global Super Admin
│   ├── businesses/page.tsx
│   └── plans/page.tsx
├── api/                          # Route Handlers y Webhooks
│   └── webhooks/
└── layout.tsx                    # Root Layout HTML con Providers (Toaster, Theme)
```

### 3.2 `src/components/` — Componentes Visuales Reutilizables
```text
src/components/
├── ui/                           # Primitivas shadcn/ui (Button, Dialog, Badge, Input, Card)
├── layout/                       # Header, Sidebar, TenantSwitcher, NavigationBar
├── forms/                        # FormField, MoneyInput, PhoneInput, ImageUpload
├── tables/                       # DataTable genérica con paginación
└── feedback/                     # CustomModal, ConfirmDialog, EmptyState, SkeletonLoader
```

### 3.3 `src/features/` — Lógica Modular por Dominio (Feature-Driven)
Cada módulo funcional encapsula sus componentes, mutaciones, consultas y tipos:
```text
src/features/
├── businesses/                   # Gestión de tenants y perfil
├── users/                        # Gestión de equipo y roles
├── products/                     # Catálogo, categorías y modificadores
├── customers/                    # Clientes y direcciones
├── orders/                       # Comandas, estados de cocina y checkout
├── payments/                     # Recaudos y cuadre de caja
├── deliveries/                   # Logística de despacho y fletes
├── expenses/                     # Salidas de dinero y egresos
└── audit/                        # Bitácora de actividad
```

### 3.4 `src/lib/` — Clientes y Utilidades Base
```text
src/lib/
├── supabase/
│   ├── client.ts                 # Cliente para Client Components (Browser)
│   ├── server.ts                 # Cliente para Server Components / Server Actions
│   └── middleware.ts             # Cliente para Next.js Middleware de rutas
├── auth/
│   └── session.ts                # Helper para extracción de JWT y user_id
└── permissions/
    └── check-permission.ts       # Verificación RBAC en servidor
```

### 3.5 `src/services/` — Adaptadores de Integración Externa
```text
src/services/
├── payments/                     # Adaptadores de pasarelas (Wompi, PSE)
├── notifications/                # Bus de notificaciones multicanal
├── whatsapp/                     # Adaptador WhatsApp Cloud API
└── email/                        # Adaptador Resend Email
```
