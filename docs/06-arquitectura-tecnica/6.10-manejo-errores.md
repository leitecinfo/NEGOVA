## 1. Objetivo

Establecer la taxonomía y el flujo unificado para la captura, clasificación, registro técnico y presentación amigable de errores en NEGOVA, impidiendo la fuga de información sensible hacia el cliente.

---

# 2. Taxonomía de Errores del Sistema

| Código de Error | Causa Raíz | Mensaje Amigable al Usuario |
| :--- | :--- | :--- |
| **`VALIDATION_ERROR`** | Datos de formulario inválidos o incompletos. | *"Revisa los campos marcados en el formulario."* |
| **`AUTH_ERROR`** | Sesión expirada o credenciales inválidas. | *"Tu sesión ha expirado. Por favor, inicia sesión nuevamente."* |
| **`PERMISSION_ERROR`** | Acción denegada por permisos del rol. | *"No tienes permisos suficientes para realizar esta acción."* |
| **`NOT_FOUND`** | Registro inexistente o no accesible en el tenant. | *"El recurso solicitado no fue encontrado."* |
| **`CONFLICT`** | Colisión de estado o duplicación de datos. | *"Esta operación entra en conflicto con el estado actual."* |
| **`DATABASE_ERROR`** | Fallo en la capa de persistencia PostgreSQL. | *"No se pudo guardar la información. Intenta de nuevo."* |
| **`EXTERNAL_SERVICE_ERROR`**| Fallo o timeout en WhatsApp/Email/Pasarela. | *"El servicio externo no respondió a tiempo. El pedido sigue a salvo."* |
| **`INTERNAL_ERROR`** | Excepción imprevista no clasificada. | *"Ocurrió un error inesperado. Nuestro equipo técnico fue notificado."* |

---

# 3. Flujo de Transformación y Presentación Segura

```text
Excepción Técnica (ej. Postgres Foreign Key Violation)
                       │
                       ▼
          [Interceptor Server Action]
                       │
         ┌─────────────┴─────────────┐
         ▼                           ▼
[Log Técnico en Servidor]   [Mensaje Sanitizado a UI]
Registra: stack trace,       Retorna: { error: "No se pudo guardar",
ip, payload para diagnóstico          code: "DATABASE_ERROR" }
                                     │
                                     ▼
                            Toast / Modal Amigable
```

> 🔒 **Regla de Seguridad:** Queda estrictamente prohibido mostrar trazas de error (stack traces), sentencias SQL, claves de API o nombres de tablas al usuario final.
