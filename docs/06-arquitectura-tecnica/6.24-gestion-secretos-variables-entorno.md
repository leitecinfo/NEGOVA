## 1. Objetivo

Establecer las directrices de seguridad para la gestión, almacenamiento y uso de secretos, claves privadas y variables de entorno en NEGOVA.

---

# 2. Separación de Variables de Entorno

```text
┌─────────────────────────────────────────────────────────────┐
│ 1. VARIABLES PÚBLICAS (Prefijo NEXT_PUBLIC_)                │
│    - Accesibles en el navegador (Client Components).        │
│    - NEXT_PUBLIC_SUPABASE_URL                               │
│    - NEXT_PUBLIC_SUPABASE_ANON_KEY                          │
│    - NEXT_PUBLIC_APP_URL                                    │
├─────────────────────────────────────────────────────────────┤
│ 2. VARIABLES PRIVADAS (Solo Servidor - Sin prefijo público) │
│    - Exclusivas para Server Actions y Route Handlers.       │
│    - SUPABASE_SERVICE_ROLE_KEY                              │
│    - WHATSAPP_API_TOKEN                                     │
│    - WOMPI_PRIVATE_KEY                                      │
│    - RESEND_API_KEY                                         │
└─────────────────────────────────────────────────────────────┘
```

---

# 3. Higiene del Repositorio de Código (Git)

- Los archivos `.env`, `.env.local`, `.env.production` están incluidos en `.gitignore`.
- Solo se incluye en el control de versiones el archivo plantilla [`.env.example`](file:///D:/Proyectos/NEGOVA/.env.example) sin secretos reales.
