## 1. Objetivo

Definir las medidas técnicas de protección contra las principales amenazas y vulnerabilidades de seguridad web (OWASP), garantizando la integridad de los datos y la resiliencia de la plataforma frente a ataques maliciosos.

---

# 2. Matriz de Protección contra Amenazas

| Vector de Ataque | Mecanismo de Defensa en NEGOVA |
| :--- | :--- |
| **SQL Injection (SQLi)** | Todas las consultas se realizan a través del cliente oficial de Supabase con consultas parametrizadas (prohibida la concatenación de cadenas SQL). |
| **Cross-Site Scripting (XSS)** | React escapa el HTML por defecto. Los campos de texto libre (nombres de platos, notas de clientes) se sanitizan con Zod. |
| **Cross-Site Request Forgery (CSRF)** | Las Server Actions de Next.js validan automáticamente el header `Origin`/`Host` y las cookies utilizan `SameSite=Lax`. |
| **Ataques de Fuerza Bruta** | Bloqueo temporal de intentos fallidos en login mediante las políticas de seguridad de Supabase Auth. |
| **Denegación de Servicio / Spam** | **Rate Limiting** en endpoints públicos sensibles (login, registro, checkout público del menú web). |
