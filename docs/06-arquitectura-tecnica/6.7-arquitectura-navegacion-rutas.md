## 1. Objetivo

Definir el mapa formal de rutas de Next.js App Router, segmentando el espacio de URLs en tres dominios independientes: **Público**, **Empresarial (Tenant)** y **Plataforma (Super Admin)**, garantizando el flujo de autenticación y redirección automática.

---

# 2. Segmentación de Rutas

```text
┌─────────────────────────────────────────────────────────────┐
│ 1. CONTEXTO PÚBLICO (Sin autenticación requerida)           │
│    /                             --> Landing comercial      │
│    /login                        --> Inicio de sesión       │
│    /register                     --> Registro de negocio    │
│    /forgot-password              --> Recuperación de clave  │
│    /m/[businessSlug]             --> Menú digital web       │
│    /m/[businessSlug]/checkout    --> Carrito y pedido       │
├─────────────────────────────────────────────────────────────┤
│ 2. CONTEXTO EMPRESARIAL (Requiere Sesión + Negocio Activo)  │
│    /[businessSlug]/dashboard     --> Resumen operativo      │
│    /[businessSlug]/orders        --> Cola de cocina         │
│    /[businessSlug]/orders/[id]   --> Detalle de comanda     │
│    /[businessSlug]/menu          --> Platos y disponibilidad│
│    /[businessSlug]/customers     --> Clientes y direcciones │
│    /[businessSlug]/finances      --> Ventas y cobros        │
│    /[businessSlug]/expenses      --> Registro de egresos    │
│    /[businessSlug]/deliveries    --> Despachos (Opcional)   │
│    /[businessSlug]/settings      --> Perfil y equipo        │
├─────────────────────────────────────────────────────────────┤
│ 3. CONTEXTO DE PLATAFORMA (Requiere Rol super_admin)        │
│    /platform                     --> Dashboard global       │
│    /platform/businesses          --> Gestión de comercios   │
│    /platform/plans               --> Catálogo de planes     │
│    /platform/features            --> Módulos globales       │
│    /platform/subscriptions       --> Facturación SaaS       │
│    /platform/audit               --> Auditoría global       │
└─────────────────────────────────────────────────────────────┘
```

# 3. Flujo de Entrada y Enrutamiento Inteligente

```mermaid
flowchart TD
    A([Usuario Ingresa al Sistema]) --> B{¿Tiene Sesión JWT Activa?}
    B -- No --> C[Redirigir a /login]
    
    B -- Sí --> D[Consultar Membresías en business_users]
    D --> E{¿Tiene Negocios Asociados?}
    
    E -- No --> F[Redirigir a /onboarding: Crear primer negocio]
    E -- Sí --> G{¿Tiene Negocio Activo Seleccionado?}
    
    G -- No --> H[Mostrar Modal Selector de Negocio]
    G -- Sí --> I[Redirigir a /[businessSlug]/dashboard]
```
