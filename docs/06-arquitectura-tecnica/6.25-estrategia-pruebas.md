---

# 3. Batería de Pruebas Críticas de Aislamiento Multi-Tenant

Se implementan tests automatizados que intentan explícitamente violar el aislamiento:

| Escenario de Prueba | Comportamiento Esperado |
| :--- | :--- |
| Usuario del Negocio A intenta leer pedidos del Negocio B | **Retorna 0 filas / 403 Forbidden** |
| Usuario del Negocio A intenta insertar un producto en Negocio B | **PostgreSQL RLS rechaza la transacción** |
| Server Action recibe pedido con `product_id` de otro comercio | **Error de clave foránea compuesta / Zod** |
| Empleado `staff` intenta registrar un gasto en `expenses` | **Bloqueo por falta de permiso `expenses.manage`** |
| Usuario sin sesión intenta consultar catálogo privado | **Redirección a `/login` / 401 Unauthorized** |
