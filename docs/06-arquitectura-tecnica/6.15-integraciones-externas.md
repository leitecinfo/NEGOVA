## 1. Objetivo

Definir la arquitectura de integración con proveedores de servicios externos (Pasarelas de Pago, WhatsApp Cloud API, Proveedores de Correo y SMS), garantizando el desacoplamiento mediante adaptadores y la protección absoluta de secretos y claves de API.

---

# 2. Organización de la Capa de Servicios (`src/services/`)

```text
src/services/
├── payments/
│   ├── index.ts                  # Interfaz unificada PaymentGatewayService
│   ├── wompi.adapter.ts          # Adaptador Wompi Colombia
│   └── bold.adapter.ts           # Adaptador Bold Colombia
├── whatsapp/
│   ├── index.ts                  # Interfaz MessagingService
│   └── meta-cloud.adapter.ts     # Adaptador oficial Meta WhatsApp API
├── email/
│   ├── index.ts                  # Interfaz EmailService
│   └── resend.adapter.ts         # Adaptador Resend / React Email
└── sms/
    ├── index.ts                  # Interfaz SMSService
    └── twilio.adapter.ts         # Adaptador Twilio SMS
```

---

# 3. Principio de Aislamiento de Secretos

```text
┌─────────────────────────────────────────────────────────────┐
│ ❌ PROHIBIDO EN FRONTEND (Navegador):                       │
│ - WHATSAPP_ACCESS_TOKEN                                     │
│ - WOMPI_PRIVATE_KEY                                         │
│ - RESEND_API_KEY                                            │
│ - SUPABASE_SERVICE_ROLE_KEY                                 │
├─────────────────────────────────────────────────────────────┤
│ ✅ PERMITIDO EN SERVIDOR (Variables de Entorno Node.js):    │
│ - Se consumen exclusivamente dentro de src/services/        │
│ - Cero exposición en el bundle JS del cliente               │
└─────────────────────────────────────────────────────────────┘
```
